*Episode 13 of 13 in a video tour of [Git Gud](https://github.com/joe-lloyd/git-gud), a desktop Git client with a lane-colored commit graph. The video is above; this is what it says, with the details.*

The companion app is Git Gud for your phone, on Android and iOS. It's for looking: checking what changed, reading a diff, following along while something runs.

To pair it, show the QR code from the host's sharing settings, or from the daemon's pair command. The phone scans it, or you paste the link.

The QR code carries the host's address and its certificate fingerprint, so the phone pins the certificate before its very first request.

## Browsing

Machines lists every paired computer and whether it's reachable right now. Tap one to see its repositories.

A repository opens on its graph. It's the same lane-colored graph, sized for a phone.

Tap a commit to read its message. The working tree tab shows uncommitted changes on the machine, and tapping a file shows its diff.

The activity tab shows the git commands the host is running.

It's all live. When the repository changes on the computer, the phone updates by itself.

## Read-only by design

The phone is read-only. Every pairing from a phone is marked read-only on the host, and the app itself refuses to send a write before it leaves the phone.

- **Read-only pairing**: The host marks every phone read-only
- **Refused on the phone**: Writes never leave the device
- **Scopes**: The host can allow fetch, pull or push, one at a time
- **Notifications**: Optional: hear when a repository changes


If you want a little more, the host can grant scopes. Allow fetch, and a Fetch button appears on the phone. Pulls are always fast-forward only, and pushes are never forced.

With notifications on, the host tells your phone when a repository changes. The notification has a Fetch now button when that scope is allowed. Only the machine, the repository and the kind of change are sent.

- **Something changes**: A commit, a fetch, a checkout
- **Host notifies**: Machine, repository and kind of event, nothing else
- **Tap Fetch now**: If the fetch scope is granted
- **No spam**: At most one per repository every thirty seconds


## How it all fits

That's the whole family. The desktop app for your work. The daemon for machines with no screen. The relay to reach them from anywhere. And the phone to keep an eye on things.

All four speak one protocol, with certificates pinned at pairing and every git command visible. Thanks for watching.
